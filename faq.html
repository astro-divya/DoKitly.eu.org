FAQ

Answers to common questions about DoKitly and its tools.

Frequently asked questions

Are DoKitly tools free?

DoKitly is built around free browser tools. Features that require a third-party API or external service are labelled accordingly.

Do my files leave my device?

Many supported tools run locally in the browser. A tool that requires a server or external API should say so before processing.

Why can a live website tool fail?

Browsers block many cross-site requests. DoKitly uses an optional serverless engine for checks that cannot reliably run from GitHub Pages alone.

Can I customize the homepage shortcuts?

Yes. Use “Edit shortcuts” below the homepage search bar. Your choices are saved only in that browser.

How do I report a wrong result?

Use the Report a Bug page in the footer and include the tool name, input and what result you expected.

Does the quiz call practice questions previous-year questions?

No. Questions should only be labelled as previous-year questions when the source is verified. Other questions are exam-pattern practice.
