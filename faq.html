FAQ

Quick answers to common questions about DoKitly.

Frequently asked questions

Is DoKitly free to use?

Yes. The tools currently available on DoKitly are free to use. If premium features are introduced later, they will be clearly labelled.

Do I need to create an account?

No. Current DoKitly tools can be used without an account or login.

Do my files leave my device?

Many supported tools process files directly in your browser. Some features need a server or external service; those features should make that clear instead of claiming local processing.

Which tools work directly in the browser?

Many image, text, calculator, converter and document operations can run locally. Live website checks, public-link reading and some AI or data features may need an internet connection or the DoKitly serverless engine.

Does DoKitly work on mobile?

Most tools are designed to work on modern desktop and mobile browsers. Very large files or advanced editing tasks may work better on a desktop.

Why do some tools need an internet connection?

Features such as public website analysis, page metadata reading, current trends or external APIs need live online data. Browser-only tools can continue to work without those services once the page is loaded.

Are Website Analyzer traffic and revenue numbers exact?

No. They are broad estimates built from public signals and a DoKitly estimation model. They are not private owner analytics and can differ substantially from actual traffic or earnings.

Why can a live website tool fail temporarily?

Target websites, public APIs and rate limits can temporarily block or delay checks. DoKitly retries supported live checks and may use cached data when appropriate.

Can I customize the homepage shortcuts?

Yes. Use “Edit shortcuts” below the homepage search bar. Your shortcut choices are saved in that browser.

How do I report a bug or wrong result?

Use the Report a Bug link in the footer and include the tool name, input and what you expected to happen.

Can I suggest a new tool?

Yes. Use the Suggest a Tool link in the footer. Useful repeat-use ideas are preferred over duplicate or low-value utilities.

Why are some tools removed or changed?

DoKitly is kept intentionally practical. Tools may be combined, improved or removed when they are repetitive, rarely useful or better handled inside another workflow.

Are exam questions copied from previous-year papers?

No. Exam Practice uses original practice questions designed to match the style and level of supported exams unless a source is explicitly identified.
