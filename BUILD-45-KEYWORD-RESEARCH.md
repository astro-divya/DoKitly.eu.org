## Evidence and limitations

- Research covered public search result themes for PDF, image, OCR, developer utilities and free-tools competitors, and inspected every sitemap page title/H1.
- URL-level keyword phrases are candidates derived from the actual tool functionality/H1 plus category SERP patterns, NOT individually verified monthly-volume keywords.
- Search volume, keyword difficulty, CPC, and DoKitly rankings are UNKNOWN without authenticated keyword research/Search Console measurements. Never represent them as verified.
- Relevance is more valuable than inflating keyword counts. Search variants with different functionality require their own pages; avoid keyword stuffing.
- Existing URLs and content are preserved. Only recommend title/H1 changes where there is a real mismatch and testing.

## Competitive SERP theme evidence

- PDF: iLovePDF/Smallpdf/Adobe and smaller browser PDF utilities compete on converter intent, OCR and privacy (e.g. https://pdftoword.tech/compare and https://pdfinfinity.com/).
- Image: image compression, conversion and background removal map to separate intents (e.g. https://gizmoop.com/image-tools).
- Developer: JSON formatter, regex tester, diff checker, CSV editor are distinct utilities (e.g. https://nextool.app/free-tools/ and https://aiotool.de/en/tools/dev).
- Content must match the actual utility, not fabricated AI/accuracy/privacy guarantees. Reference: https://developers.google.com/search/docs/fundamentals/creating-helpful-content
