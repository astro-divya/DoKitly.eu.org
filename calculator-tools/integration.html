Symbolic and definite integration

Indefinite integration returns an antiderivative plus the constant of integration. Definite integration uses the selected lower and upper bounds.

Not every mathematical expression has an elementary closed-form antiderivative. If the symbolic engine cannot fully integrate an expression, use the Numerical Methods calculator for trapezoidal or Simpson approximation.
