Matrix & Linear Algebra Calculator

Calculate determinants, inverses, transposes, RREF, matrix arithmetic and solve Ax = b.

Enter a matrix using spaces or commas between values.

Matrix operations

Enter each matrix row on a new line. Values can be separated by spaces or commas. Determinant and inverse require a square matrix; multiplication requires compatible dimensions.

The RREF and linear-system functions use numerical row reduction, so very ill-conditioned matrices can accumulate floating-point error.
