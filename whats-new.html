Latest release · Build 39 · 15 October 2026

A cleaner, more human tool-reading experience without changing the tool engines.

Readable typography

Strengthened heading, body and secondary-text contrast across tool information sections, with matching dark-mode readability.

Cleaner tool guides

Reworked the shared tool-guide presentation into an open editorial layout with clearer spacing, calmer hierarchy and no decorative card wall.

Duplicate cleanup

Removed the Build 38 generic value/FAQ block from 12 pages that already had richer hand-written tool guides, keeping the stronger page-specific content instead.

FAQs & related tools

Refined FAQ disclosure rows, related-tool navigation and helpful-guide links so the lower page reads like a useful guide rather than a generated table.

Engine preservation

PDF, OCR, Background Remover and other processing engines were not changed in Build 39.
