What’s New

See the latest useful additions and fixes in DoKitly.

Latest release · Build 36

Local Mozilla PDF.js foundation and search/preview reliability fixes.

Mozilla PDF.js 6.4.299

PDF rendering now uses the packaged local Mozilla PDF.js 6.4.299 build with its exact matching worker instead of the legacy CDN runtime.

PDF tool wiring

PDF Editor, PDF to Word, PDF to JPG/PNG, PDF previews and OCR PDF loading share the same local PDF.js foundation.

144-tool search

The global search registry now contains all 144 production tool entries, including the six newest tools and useful OCR aliases such as Image to Text and PDF OCR.

OCR preview fit

OCR images and PDF pages fit inside the preview viewport while preserving aspect ratio; Zoom In, Zoom Out, Fit and panning remain available.

Scope note

This release changes OCR PDF loading and preview behavior, not the OCR recognition engine itself. Recognition-quality/orientation upgrades remain a separate engine task.
