What’s New

See the latest useful additions and fixes in DoKitly.

Build 11 highlights

  • Website Analyzer: rebuilt as a more readable Website Intelligence Report with larger cards, clearer hierarchy and collapsible technical data.
  • Traffic estimation: stronger public-signal calibration using popularity and web-footprint signals so large, crawler-blocking sites are less likely to be treated as tiny sites.
  • Interactive charts: animated traffic-scale, popularity-rank, signal-strength and modeled-channel visuals with hover/tap values.
  • Reliability: optional checks fail independently, the Worker retries key requests, and the browser can reuse a recent successful full report when the live engine is temporarily unavailable.
  • Performance handling: PageSpeed remains optional to the rest of the report, with clearer rate-limit/unavailable states.

About estimates

Traffic, engagement, channel mix, ad revenue and website value are directional estimates based on public signals. They are shown as ranges or modeled values and are not presented as private owner analytics.
