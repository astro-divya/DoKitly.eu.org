01 LATEST UPDATE

A smoother, more useful DoKitly

This Build 44 candidate brings richer category guides, clearer mobile upload flows and consistent export branding. Existing PDF, Image and other tool engines remain the baseline; no untested feature is claimed as production-certified.

01

Explore categories with confidence

Category introductions now use genuinely relevant examples, colorful guide headings, larger icons and easier-to-scan tool navigation.

02

Upload on mobile, clearly

Image/PDF upload controls are prioritised on narrow screens. The mobile processed preview appears only when an actual result is ready; desktop retains its established workspace.

03

Share branded practice quizzes

Smart Quiz exports to PDF or editable Word with a light navy/teal document theme, generous diagonal DoKitly watermark, page numbers and optional answer keys.

04

Better tool and guide discovery

Improved category hero balance, more readable tool names, full-width spacing and repeatable accessible editorial animations.

Release note

This is a Build 44 staging candidate, not a claim that every browser/device or every tool conversion is fully tested. Check real outputs before relying on important documents or image edits.
