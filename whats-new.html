What’s New

See the latest useful additions and fixes in DoKitly.

Build 17 highlights

  • Download File Ready flow: browser-generated files are handed to a dedicated noindex download page through temporary IndexedDB storage, with file details, privacy information, an AdSense-safe separated ad area and direct-download fallback.
  • Typing Test corrections: keyboard-unfriendly Unicode symbols were removed, corrected words stay clean in the lower typing stream, while mistake history remains visible only in the upper reference passage.
  • Refined balanced headers: tool headers are more compact and fade vertically into the page instead of looking like a separate boxed card.
  • Premium icon redraw: homepage category icons and tool icons were redrawn as real blue/teal duotone pictograms and cache-busted so the new artwork actually renders.
  • AdSense readiness: the publisher verification meta tag is preserved across HTML pages and ads.txt is included at the site root.

Migration note

The public site identity is now dokitly.in. GitHub remains the hosting repository, while visitor-facing SEO and navigation use the custom domain.
