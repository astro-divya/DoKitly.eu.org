What’s New

See the latest useful additions and fixes in DoKitly.

Build 20 highlights

  • GA4 site-wide analytics: Google Analytics 4 (G-80KFT4220E) is loaded once on every public HTML page, with shared privacy-conscious event tracking for tool opens, file selection, processing, downloads, resets and related-tool navigation.
  • Compact seamless tool headers: Flagship image, PDF, QR, Website Analyzer and typing pages now use a shorter header that fades naturally into the page instead of looking like a separate strip.
  • Bigger icon-family visuals: Selected tool headers use larger glossy tool icons placed closer to the right-center, and homepage category/popular icons are more prominent.
  • Typing timer behavior: Start Test now prepares the test; the countdown begins only when the first printable character is actually typed.
  • SEO and indexing hygiene: Production-domain metadata is preserved, deliberate duplicate/utility pages remain noindex, canonical public pages stay indexable, and the sitemap excludes noindex/error pages.
  • 404 and favicon: A branded recovery page and root favicon files are included for better navigation and search/browser icon discovery.
  • Privacy and download tracking: Privacy wording now covers GA4 and AdSense, while the shared analytics layer never sends file names or file contents.

Migration note

The public site identity is now dokitly.in. GitHub remains the hosting repository, while visitor-facing SEO and navigation use the custom domain.
