What’s New

See the latest useful additions and fixes in DoKitly.

Latest release · Build 35

One current Mozilla PDF.js runtime across DoKitly PDF-reading and rendering paths.

Mozilla PDF.js 6.4.299

Build 35 replaces the previous PDF.js 3.11.174 runtime with one pinned 6.4.299 display build and its exact matching worker.

Single runtime path

PDF to Word, PDF Editor, OCR PDF input, PDF image conversion, previews and shared PDF rendering now resolve through the same PDF.js runtime.

Old runtime removed

Legacy 3.11.174 script and worker references were removed so PDF.js-based testing cannot silently fall back to the old runtime.
