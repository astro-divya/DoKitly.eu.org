What’s New

See the latest useful additions and fixes in DoKitly.

Build 19 highlights

  • Download page hotfix: The File Ready page now uses a properly sized DoKitly header and the final Download File action bypasses the shared handoff interceptor, so the saved Blob downloads instead of being routed back into another File Ready flow.
  • Flagship SEO upgrade: Major PDF, image, typing, QR and Website Analyzer pages now include unique search-focused titles, descriptions, useful help content, visible FAQs and related-tool links below the working tool.
  • Homepage icon fix: The homepage JavaScript now renders the same premium SVG assets shown in the initial HTML, preventing the old emoji icons from replacing them after page load.
  • Richer icon family: Category icons, tool icons and contextual tool visuals now use category-specific multicolor duotone palettes instead of one repetitive blue/teal treatment.
  • Compact blended headers: Major tool headers use a consistent reduced height and a smoother vertical fade into the page background.
  • Opening-position fix: Fresh tool-page loads and reloads start at the top unless a deliberate anchor is present; normal browser Back/Forward restoration is preserved.
  • SEO hygiene: Custom-domain canonicals, social metadata, sitemap/robots rules, AdSense verification and ads.txt are preserved.

Migration note

The public site identity is now dokitly.in. GitHub remains the hosting repository, while visitor-facing SEO and navigation use the custom domain.
