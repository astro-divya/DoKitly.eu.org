Latest source update · Build 43 · 20 October 2026 · QA candidate — not yet deployed

Document reliability, study tools and more transparent image editing

Improved PDF-to-Word editable document output and controlled scanned-page handling; OCR Studio now handles large PDFs one page at a time, cancels stale selections, frees temporary canvases and preserves partial recognized text for retry. Complex document fidelity still depends on the source.

World Quiz retains 15 exam profiles, with corrected SSC MTS session-wise scoring, UPSC practice question selection and negative-marking precision. Dated, source-linked current affairs are a manually verified October 2026 snapshot, not a continuously updated feed or authenticated official PYQ corpus.

Background Remover keeps U2NetP Fast as its default. Optional Silueta Detail and experimental Balanced comparison provide alternate results, original-resolution PNG export and manual Refine controls. Comparison processing was tested on Windows, but difficult-image hair, glass and adjacent-background removal are not proven flagship quality; Detail is not guaranteed to improve output.

Homepage font requests and hidden-theme hero loading were optimized without replacing the approved artwork, and a headline overlap was corrected. Isolated responsive layouts passed; an intermittent Windows cold homepage navigation timeout remains unresolved. Production PageSpeed and full hosted-device acceptance are still pending. No AdSense approval is implied.

Previous source update · Build 42 · 17 October 2026

Signature design, verified redirects and local-first tool libraries

Integrated the approved PDF-to-Word C3.3 reference and 100 more canonical tool guides. Improved comparison, example and FAQ headings without replacing tool engines. All 101 guides retain tool-specific explanations, visible FAQs and matching FAQPage structured data, including two schemas embedded in JSON-LD @graph.

Audited 48 aliases with a single redirect destination per alias, preserved their query-mode handoffs and tested selected interactive modes. Bundled licensed pdf-lib 1.17.1, jsPDF 2.5.1, docx 8.5.0 and nerdamer 1.1.13 as genuine local JavaScript files, with CDN fallbacks if local loading fails.

Build 42 stabilization additionally corrected four repetitive search titles and performed isolated desktop/mobile/dark rendering checks, vendor API tests, link checks and source regression checks. Full deployed-browser navigation and actual end-to-end PDF/OCR/image conversions have not been certified. AdSense approval is not implied.
