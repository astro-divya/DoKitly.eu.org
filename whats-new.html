What’s New

See the latest useful additions and fixes in DoKitly.

Build 12 highlights

  • Custom domain migration: DoKitly is now prepared for https://dokitly.in with refreshed sitemap, robots.txt, canonical URLs, Open Graph/Twitter metadata, structured data, manifest paths and GitHub Pages CNAME.
  • Typing Test: moved to its own focused page with Easy/Medium/Hard difficulty, Normal/Strict/God modes, a 2–3 line moving passage window and an animated focus view.
  • Hindi InScript Tutor: now has its own learning page with physical-key validation, Shift-aware mappings, finger guidance, lessons, on-screen keyboard highlights, a recall game and KeymanWeb-powered free practice when available.
  • Website Analyzer: improved root-domain handling for RDAP/DNS/traffic signals, better robots/sitemap discovery, Build 12 Worker reliability and clearer report readability.
  • Visual polish: premium category icons and light card/button refinements were added without changing DoKitly’s overall design direction.

Migration note

The public site identity is now dokitly.in. GitHub remains the hosting repository, while visitor-facing SEO and navigation use the custom domain.
