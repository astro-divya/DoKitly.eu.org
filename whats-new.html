What’s New

See the latest useful additions and fixes in DoKitly.

Latest release · Build 34

Cleaner file workflows and focused OCR, watermark and PDF-to-Word improvements.

File drag & drop

A shared drag-and-drop layer now connects dropped files to the same native file-input change path used by Choose File across file-input tools.

Preview controls

Visual preview surfaces can use compact Zoom In, Zoom Out and Fit controls with mouse or touch panning where appropriate.

Footer QR

The desktop/tablet QR is larger inside the existing footer strip. The complete QR strip is hidden on mobile at 760px and below.

Watermark Remover

Remove mode opens first, uses automatic detection by default, and keeps only a simple rectangular Select Area fallback instead of brush and mask controls. Processed output retains Before/After comparison.

OCR Studio

Image and scanned-PDF preview, Auto/English/Hindi/Hindi+English OCR modes, page navigation, Fit/Zoom/Pan, editable text, Copy, TXT and Word export are available in one compact workflow.

PDF to Word

The editable DOCX reconstruction path now preserves more source font identities and detects centered/right-aligned text while keeping the existing scanned-page OCR/image fallback.
