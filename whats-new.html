Latest release · Build 33

Focused functional repair.

Build 31 prioritizes working output over release labels: regressed PDF engines are restored, Background Remover now uses a dedicated browser ML model first, watermark reconstruction is improved, and tool workspaces no longer depend on a giant decorative outer card.

PDF regression recovery

PDF Editor, PDF-to-Word and shared PDF processing use the earlier stable engine baseline instead of the later Build 30 regression.

Background Remover engine

A dedicated browser ML background-removal model is attempted first; the older edge and portrait engines remain safe fallbacks.

Watermark reconstruction

Masked removal now reconstructs inward from surrounding real pixels instead of relying on the previous eight-sample flat fill.

Open tool workspace

The giant outer tool panel is neutralized globally while compact upload, input, preview and result surfaces remain available where functional.

Mobile QR cleanup

The phone QR section is completely removed from mobile layout, including its reserved space; desktop and tablet presentation remains available.

Deployment hygiene

Root ads.txt, favicon declarations, CNAME, robots, sitemap and static GitHub Pages delivery files are included and rechecked for deployment.
