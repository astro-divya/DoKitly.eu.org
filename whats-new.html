Latest release · Build 28

Open premium layouts with less card chrome.

Homepage, directory, category and tool pages now use open spacing and dividers instead of decorative white boxes, while functional controls keep clear local surfaces.

Homepage hero

Selected Gemini hero artwork is layered behind the headline/search area, with no giant white hero slab.

Compact popular launcher

Popular Tools is folded into a horizontal icon-and-name launcher below search to save vertical space.

Open directories

Homepage categories, All Tools and category pages use open grids with larger approved artwork and content-fit spacing.

Clickable All Tools strip

Category jump navigation supports click-to-section, active state, wheel scrolling, drag, touch swipe and keyboard scrolling.

Tool + SEO layout

Only the compact translucent tool hero remains a primary boxed surface; workspace and SEO/help sections use open editorial layouts.

Interaction refinements

Feedback hides backend diagnostics, date/time input is locked to HH:MM:SS.ffffff, and touch layouts do not depend on hover.
