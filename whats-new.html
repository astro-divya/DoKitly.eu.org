What’s New

See the latest useful additions and fixes in DoKitly.

Build 16 highlights

  • Typing Test final UX: single Start → Finish primary button, compact Pause/Restart, reliable Exit Focus, persistent locked words, book-like spacing and richer educational Easy/Medium/Hard passages with natural numbers, brackets and symbols.
  • Balanced tool headers: major tool pages now use one compact premium header with a tool-specific duotone icon, right-side contextual visual and subtle background blend without adding a separate page section.
  • One icon family: homepage, All Tools, category tool cards and major tool-page headers now use the same glossy blue/teal duotone icon system instead of mixed emoji and plain icons.
  • PDF Editor cleanup: the static balanced header is the single visible page heading; dynamically generated duplicate tool headings are suppressed while the editor workspace remains unchanged.
  • AdSense verification: the ca-pub-9623211628880604 verification meta tag is preserved inside the head of every HTML page, including the homepage.

Migration note

The public site identity is now dokitly.in. GitHub remains the hosting repository, while visitor-facing SEO and navigation use the custom domain.
