Latest release · Build 37 · 15 October 2026

Background removal, OCR and processing experience updates.

Background Remover

Uses the compact fast background-removal path selected during Build 37 testing, with transparent PNG reconstruction and worker-based processing.

OCR Studio

Keeps the accepted Tesseract.js OCR workflow with English/Hindi support and the existing export flow.

Processing experience

Processing previews use procedural mixed-size colorful glints with randomized position, timing, size, rotation and a short completion burst, alongside the spinner and progress presentation.

Preserved PDF tools

PDF→Word, PDF Editor and the Build 36 PDF.js runtime remain unchanged by the Build 37 engine work.
