Privacy

How DoKitly handles files, browser storage and future account features.

Privacy and browser processing

Many DoKitly tools process files and text directly in your browser. For browser-only tools, DoKitly does not intentionally send the file contents to DoKitly servers. Some generated downloads may be stored temporarily in your browser so the File Ready page can deliver them.

Google Analytics 4

DoKitly uses Google Analytics 4 to understand site usage and important interactions, such as opening a tool, selecting a file, starting or completing a tool action, and clicking a download. DoKitly's analytics helper is designed not to send uploaded file names, file contents, generated file contents or other private file data to Google Analytics.

Google AdSense

DoKitly integrates Google AdSense for advertising and site monetization. Where ads are served, Google and its advertising technologies may process information according to Google's own services, settings and applicable requirements. Ads are kept separate from tool actions and downloads.

Local browser storage

Some features use local browser storage for temporary generated files, preferences or convenience settings. Clearing browser site data can remove those locally stored items.

External libraries

Some tools may load open-source libraries from public content delivery networks. Those providers may receive normal web request information when their resources are loaded.

Browser-only and server-backed processing

Most DoKitly file utilities process files in your browser and do not upload file contents. Features that explicitly use a live backend or third-party service are labelled in their interface. Google Analytics and AdSense may process usage, device, cookie or advertising data according to their own policies; DoKitly analytics events must not include filenames, entered text, OCR text, CSV contents, secrets or file contents.
