Privacy

How DoKitly handles files, browser storage and future account features.

Privacy on the test build

Many DoKitly tools process data in your browser. Files are not intentionally uploaded by those browser-only tools. Some features may load open-source libraries from public CDNs.

Some tools may use local browser storage for convenience settings. Clearing site data can remove locally saved preferences. Future account sync will require a separate privacy update before launch.
