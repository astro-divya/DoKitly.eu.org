About this tool

DoKitly QR Studio is a free QR code generator and decoder that works directly in the browser. Create a code for plain text or a URL, Wi-Fi credentials, email, phone, SMS or a vCard contact, then choose the output size and colors before downloading a PNG. The same page also includes a scan/decode mode for QR images. No account is required, and the generated payload is shown by the controls you enter rather than being hidden behind a shortened link. Test the final code with more than one scanning app before printing or publishing it widely.

How to Create a QR Code

Choose the QR type, enter the requested information and select a size. For ordinary links and text, use Text / URL. Other modes format your entries into standard payload strings for Wi-Fi, email, phone, SMS or vCard contact data. Generate the code, check the preview and download the PNG when it looks correct.

What Can a QR Code Store?

A QR code stores text. Apps interpret certain text formats as actions, such as opening a URL, joining Wi-Fi, composing an email or importing contact details. The amount of data affects visual density, so shorter payloads are usually easier to scan at smaller physical sizes.

URL, Text, Wi-Fi and Contact QR Codes

URL codes are useful for websites, menus and documents. Text codes can contain a short message or identifier. Wi-Fi mode includes the network name, password and security type in a standard Wi-Fi payload. vCard mode can include name, phone, email and organization information for compatible scanner apps.

QR Size, Colors and Print Quality

Larger pixel dimensions are useful when the code will be placed into another design or printed. Maintain strong contrast between foreground and background; dark modules on a light background are the safest choice. Decorative color combinations can look attractive but should always be tested with more than one scanner before printing many copies.

Download and Scan QR Codes

Generated codes can be downloaded as PNG images. The Scan / Decode tab lets you choose an existing QR image and attempt to read its contents in the browser. Image quality, crop, contrast and scanner support can affect decoding, so use a clear image with the complete code visible.

Privacy and QR Best Practices

A QR code is not encryption. Anyone who scans it can read the stored payload, so do not embed secrets that should remain private. Test the final code at the physical size where it will be used, leave quiet space around the code, and verify links before distributing printed material. DoKitly does not require a redirect service for ordinary generated payloads.

Before You Publish a QR Code

Always scan the final exported PNG before placing it on a poster, label or document. Then test again after the code has been resized inside the design. Leave clear space around all four sides and avoid placing text or decorative graphics over the modules. For a URL, confirm the destination uses the exact address you intend. For Wi-Fi or contact data, remember that anyone who can scan the code can read the encoded information.

Choosing the Right Payload

Use a normal URL payload when you want the scanner to open a web page, Wi-Fi mode when you want compatible devices to offer network joining, and vCard when the goal is contact import. Avoid placing long marketing copy inside the code when a short landing-page URL would be easier to scan. Shorter payloads produce less dense QR patterns and are generally more forgiving at smaller printed sizes.
