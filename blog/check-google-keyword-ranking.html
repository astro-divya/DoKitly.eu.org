How to Check Your Google Keyword Ranking

Learn what Google keyword ranking means, how Search Console average position differs from live rank, and how to track useful ranking trends.

Practical guideUpdated for DoKitly Build 21

What keyword ranking means

A keyword ranking describes where a page appears when a search engine shows results for a query. Position 1 is generally more prominent than position 20, but modern search pages are not a simple list of ten identical blue links. Maps, images, videos, featured answers, shopping modules and other features can change the layout.

That is why rank tracking should focus on trends and visibility rather than treating one manual search as an absolute truth for every user.

Use Google Search Console for first-party performance data

Google Search Console reports how verified sites performed in Google Search. Performance data can include queries, pages, clicks, impressions, CTR and average position. This makes it useful for understanding which searches actually produced impressions for your pages.

Search Console is different from a live SERP scraper. Its average-position metric aggregates impressions from real search contexts over the selected period.

Average position is not an exact live rank

If Search Console says a query has an average position of 18.4, it does not mean every user always saw the page at exactly result 18. The position may have been higher for some devices or locations and lower for others. The average summarizes those impressions.

DoKitly's Keyword Rank Checker labels its derived page grouping as Approx. Results Page. It uses ceil(position / 10) for a simple page-style grouping, so 18.4 maps to approximately page 2. That is a convenience label, not a claim about an exact current Google page.

Step-by-step: check ranking data

  1. Open Google Search Console for a site you are authorized to manage.
  2. Choose the performance report and date period. Common comparisons use 7, 28 or roughly 90 days.
  3. Export the query data as CSV when you want to analyze it outside Search Console.
  4. Open the DoKitly Keyword Rank Checker.
  5. Import the CSV. The current DoKitly CSV mode reads supported exports in the browser and does not pretend the data is a live SERP scrape.
  6. Filter a keyword or ranking URL.
  7. Review position together with impressions, clicks and CTR. A position number without visibility or traffic context can be misleading.

Why rankings vary by location

Search results can differ between countries, cities and even nearby users, especially for local-intent queries. A restaurant search is an obvious example, but location can influence many other queries too. When your dataset includes country information, compare like with like rather than mixing markets.

Device differences

Mobile and desktop result pages can differ in layout and behavior. A site can also perform differently because of mobile usability, page speed or user intent. If device data is available, separate it before drawing conclusions from an overall average.

Branded vs non-branded keywords

Branded queries include your brand or product name. They often have different intent and ranking patterns from broader non-branded searches. Separate the two when evaluating SEO growth. A site can dominate branded queries while still having little visibility for the topics it wants to reach.

Track trends instead of daily noise

Rankings naturally move. Search engines update indexes, competitors change pages, seasonal interest shifts and result layouts evolve. A one-day dip is not automatically a problem. Look for sustained movement across meaningful periods and compare the current period with a previous equivalent period when comparable data is available.

For example, moving from an average position of 26.1 to 18.4 represents an improvement of 7.7 positions in the average metric. It is still an aggregate measurement, but the direction can be useful when supported by impressions and clicks.

Find practical opportunities

Positions 4–10

These queries are already on the first results page in a simplified ten-results model. Review whether the page fully answers intent and whether its snippet is competitive.

Positions 11–20

Page-two-type opportunities can be valuable because relatively modest relevance or authority improvements may move a query into more visible territory.

High impressions, low CTR

If a query appears frequently but attracts few clicks, review the title, description and whether the page matches the searcher's goal. Low CTR is a prompt to investigate, not proof that the snippet alone is the problem.

Manual searches have limitations

Searching your own keyword repeatedly is not a reliable measurement system. Personalization, location and device can affect what you see. Incognito mode reduces some personalization but does not remove geography or all contextual factors. Use Search Console or a reputable rank-tracking provider for structured measurements.

Live SERP checks need a real provider

A responsible rank checker should not fabricate positions or call an average position “live.” Directly scraping search-result HTML can also trigger blocking and CAPTCHAs. DoKitly's current live SERP mode remains inactive until a reliable provider is configured.

Separate ranking changes from demand changes

A fall in clicks does not always mean a ranking loss. Search demand can decline while average position stays stable, or impressions can rise because a page begins appearing for many broader queries at lower positions. Review impressions, clicks, CTR and position together before deciding what happened.

Seasonality is especially important. Compare similar periods when possible—such as the same month year over year for seasonal topics—instead of assuming every week should outperform the previous one.

Use ranking URLs to detect overlap

If multiple pages appear for very similar queries, inspect whether they serve distinct intents or compete with one another. Search Console page filters can help identify which URL receives impressions for a query. Do not merge or redirect pages solely because two URLs appear; first understand whether each page has a legitimate purpose.

Document important SEO changes

Keep a simple change log for major title edits, content rewrites, redirects and technical releases. When ranking trends move weeks later, the log gives you context. Without it, teams often guess which change caused a movement and can reverse useful work unnecessarily.

A simple weekly ranking review

A useful ranking routine does not require checking every keyword every day. Review a consistent period, compare it with a similar earlier period, and focus on queries that have enough impressions to be meaningful. Separate branded searches from non-branded topics, note which landing page is receiving impressions, and watch whether clicks move in the same direction as position. A small position change can be noise, especially across devices or countries, so look for repeated movement over time. Keep annotations for major content changes so later gains or drops have context.

FAQ

What is a good Google position?

There is no universal number that guarantees traffic. Relevance, search volume, result features and CTR all matter. Positions closer to the top generally receive more visibility.

Why is my Search Console position different from what I see?

Search Console averages impressions across contexts. Your manual search represents one context at one moment.

How often should I check rankings?

For most sites, weekly or monthly trend review is more useful than reacting to every daily movement.
