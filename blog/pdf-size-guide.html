How to Reduce PDF Size

PDF size is often driven by embedded images, scanned pages, fonts and repeated assets.

Start with images

Scanned or photo-heavy PDFs are usually large because every page contains a high-resolution image. Reducing image dimensions and JPEG quality can make the biggest difference.

Keep readable resolution

For screen reading, extremely high DPI is often unnecessary. Test the compressed file at normal zoom before deleting the original.

Do not overwrite the only copy

Compression can be lossy. Keep the source file when the document is important.
