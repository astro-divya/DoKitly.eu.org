How to Reduce PDF Size

PDF size is often driven by embedded images, scanned pages, fonts and repeated assets.

Start with images

Scanned or photo-heavy PDFs are usually large because every page contains a high-resolution image. Reducing image dimensions and JPEG quality can make the biggest difference.

Keep readable resolution

For screen reading, extremely high DPI is often unnecessary. Test the compressed file at normal zoom before deleting the original.

Do not overwrite the only copy

Compression can be lossy. Keep the source file when the document is important.

Identify the reason the PDF is large before compressing it

Two PDFs with the same number of pages can differ greatly in size. A scanned document may contain a full-page photograph on every page, while a digitally generated invoice might contain mostly text and a few vector drawings. The scanned document often has far more image data to reduce. Inspect a few pages at high zoom: if letters turn visibly pixelated, the page is probably image-based. If text stays crisp and selectable, the PDF may contain fonts and drawing instructions instead. Compression settings that help a stack of scans may make little difference to a text-heavy file.

Practical example: reducing a scanned document

Imagine a 20-page PDF containing color scans of printed forms. Its large size comes mainly from the page images. If the document is needed for ordinary on-screen reading, reducing excessive image resolution or converting nonessential color scans to grayscale may lower size. But do not assume every document can safely become black and white: a signature, colored annotation or stamp may depend on color. Before choosing a stronger setting, compare small text, signatures, thin lines and shaded boxes in the resulting PDF against the original. If those details disappear, the size saving is not worth the loss.

Practical example: a presentation exported to PDF

A slide deck exported to PDF might repeat a high-resolution background or contain full-resolution photographs originally intended for print. Resizing those photographs before exporting from the presentation software can be more effective than repeatedly compressing the finished PDF. If you can edit the source presentation, consider preparing a smaller-screen version and exporting again. A PDF compressor cannot restore editing controls to flattened pictures and may not be able to identify which embedded image was oversized for its visual role.

Lossless optimization versus lossy compression

Lossless optimizations can remove redundant structure, consolidate eligible repeated objects or improve how compatible data is stored without intentionally discarding image detail. Lossy image compression changes image data to reduce bytes. JPEG-like losses may show up as blocks or halos around lettering and sharp lines. Because different documents contain different objects, the same preset can produce major savings for one file and almost none for another. A compressor can even produce a slightly larger output if its rewriting overhead exceeds the gains. That does not always mean the tool is broken.

How to compare the before and after

Record the original file size, then run a moderate compression setting. Open the output in a PDF viewer and compare the page count, text readability, page orientation and any pages containing detailed figures. At ordinary zoom, check whether the print looks natural; at 200% or more, inspect a few labels and diagrams. If the PDF will be printed, test-print an important page before distributing a large batch. If it contains live form fields, internal links, bookmarks, signatures or layers, verify those features separately rather than assuming visual similarity guarantees full functional preservation.

Documents that require extra caution

Signed PDFs can contain cryptographic signatures that may become invalid when the document is rewritten. Some encrypted or permission-protected documents may not be compressible without the authorized password or software. Archival or compliance-sensitive documents may require preservation of metadata, exact page structure or embedded fonts. For such material, do not replace the only original with a compressed copy. Ask the receiving organization which file types, signatures and formatting characteristics it accepts before optimizing.

Why compressing repeatedly can make the result worse

Compressing an already recompressed photograph can introduce cumulative artifacts without substantial additional savings. Instead of cycling the same output through multiple tools, restart from the original file and test distinct quality settings. Decide on your actual requirement—for example, below a form upload limit—and stop once you meet it with acceptable readability. If a large scan must stay legible, splitting the pages into separately allowed uploads may be preferable where the destination permits it.

Frequently asked questions

Will compressing always reduce size?

No. Already optimized PDFs and files containing mostly efficient text or vector content may change very little.

Can compression remove searchable text?

Certain workflows that rasterize pages can remove or obscure editable/selectable text. After processing, try selecting words in the output rather than assuming it remains searchable.

Should I use grayscale for official documents?

Only if color is not required to interpret stamps, diagrams, annotations or the receiving organization's requirements.
